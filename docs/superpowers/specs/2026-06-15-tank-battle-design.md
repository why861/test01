# 坦克大战 — 设计文档

**日期**: 2026-06-15  
**状态**: 待实现

---

## 一、概述

基于 Python + Pygame 的坦克大战小游戏，支持单人闯关和本地双人对战，地图随机生成。

## 二、技术选型

| 项目 | 选择 |
|------|------|
| 语言 | Python 3 |
| 图形库 | Pygame |
| 地图 | 13×9 网格，随机生成 |
| 画面尺寸 | 780×580 像素（每格 60px，右侧 60px 作信息栏） |

## 三、项目文件结构

```
tank_battle/
├── main.py          # 入口 + 主菜单
├── settings.py      # 所有常量配置
├── map.py           # 随机地图生成
├── tank.py          # 坦克类（玩家 & 敌人）
├── bullet.py        # 子弹类
├── ai.py            # 敌人 AI
├── game.py          # 游戏主控制器
└── assets/          # 图片/音效（先用几何图形绘制）
```

## 四、核心模块职责

### settings.py
- 屏幕尺寸、颜色常量
- 坦克移动速度、子弹速度
- 血量、伤害、网格大小
- 各类道具配置（预留）

### map.py
- 13×9 网格地图
- 随机放置元素：砖墙（可摧毁）、铁墙（不可摧毁）、水域（不可通行，子弹可通过）
- 玩家出生点和敌人出生点标记为空地
- 提供 `is_passable(x, y)` 和 `is_destroyable(x, y)` 接口

### tank.py
- 坦克基类：位置（网格坐标）、方向（上下左右）、移动、射击、碰撞检测
- 玩家类：继承坦克，绑定键盘输入
- 敌人类：继承坦克，由 AI 模块驱动
- 血量：玩家 3 条命，敌人 1 条命

### bullet.py
- 子弹：直线飞行、速度固定
- 碰撞检测：击中砖墙(销毁墙+子弹)、铁墙(仅销毁子弹)、坦克(扣血+销毁子弹)、边界(销毁子弹)
- 友方子弹不伤及自己

### ai.py
- 敌人行为决策：移动（随机 + 概率追踪玩家）+ 射击（间隔 + 概率射击）
- 难度由配置参数控制

### game.py
- 游戏主循环：初始化 → 地图生成 → 波次管理 → 判定胜负 → 结束
- 双人模式：两个玩家共享屏幕，互相可见
- 单局流程：消灭所有敌人即为胜利，玩家全部阵亡即为失败

### main.py
- 主菜单界面：模式选择（单/双人）、难度选择（简单/普通/困难）
- 调用 game 模块启动游戏

## 五、游戏流程

```
主菜单 → 选择模式
       ├─ 单人模式 → 选择难度（简单/普通/困难）
       └─ 双人模式 → 直接开始
       → 生成随机地图
       → 战斗阶段（消灭所有敌人/玩家阵亡）
       → 胜利/失败界面 → 返回主菜单
```

## 六、操作方式

| 功能 | 玩家1（单人模式） | 玩家2（双人模式） |
|------|-------------------|-------------------|
| 上  | ↑                 | W                 |
| 下  | ↓                 | S                 |
| 左  | ←                 | A                 |
| 右  | →                 | D                 |
| 射击 | +                 | F                 |

## 七、难度设计

| 难度 | 敌人数量 | 敌人速度 | AI 追踪概率 | AI 射击频率 |
|------|----------|----------|-------------|-------------|
| 简单 | 3        | 慢       | 20%         | 低          |
| 普通 | 5        | 中等     | 40%         | 中          |
| 困难 | 7        | 快       | 60%         | 高          |

## 八、地图元素

| 元素 | 可通行 | 可摧毁 | 颜色 |
|------|--------|--------|------|
| 空地 | 是     | —      | 黑色 |
| 砖墙 | 否     | 是     | 棕色 |
| 铁墙 | 否     | 否     | 灰色 |
| 水域 | 否     | 否     | 蓝色 |

- 空地占地图约 60%，保证足够移动空间
- 玩家/敌人出生点强制为空地

## 九、不包含的功能

- 道具/强化系统（纯走位和射击）
- 网络联机
- 关卡编辑器
